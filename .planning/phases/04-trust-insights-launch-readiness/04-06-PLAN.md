Create features/billing/reconcile.ts (pure):
- `export const BUILD_PURPOSE_REF: Record<MeteredPurpose, LedgerEntry["refType"]> = { interview_turn: "interview", embedding: "source", sandbox_message: "agent", chat_message: "conversation" }`.
- `export type ReconcileIssue` is a discriminated union on `kind`:
  - "duplicate_id" (id)
  - "balance_chain" (identityId, entryId, expected, actual)
  - "negative_balance" (identityId, entryId, balance)
  - "usage_split_mismatch" (conversationId, hirerDebitCents, splitCents)
  - "orphan_split_row" (entryId, conversationId)
  - "purpose_ref_mismatch" (entryId)
  - "markup_outside_usage" (entryId)
  - "cashout_without_payout" (entryId)
  - "payout_without_cashout" (payoutId)
  - "cashout_amount_mismatch" (payoutId, ledgerCredits, payoutCredits)
  - "payout_rate_mismatch" (payoutId)
- `export type ReconcileReport = { ok: boolean; issues: ReconcileIssue[]; totals: { hirerDebitCents; platformCostCents; platformMarginCents; expertEarningsCents; buildChargeCents; cashoutCents } }`.
- `export function reconcileLedger(input: { ledger: LedgerEntry[]; payouts: Payout[] }): ReconcileReport` runs these checks:
  - ids are unique
  - per identity, rows sorted stably by createdAt in input order keep a running sum that equals each non-null balanceAfter and never goes below 0
  - every debit whose purpose is set has the refType from BUILD_PURPOSE_REF
  - platform_margin and earnings rows only reference conversations
  - per conversation that has chat debits, the negated sum of debits equals platform_cost + platform_margin + earnings for that refId
  - a platform or earnings row for a conversation with no chat debit is an orphan
  - each cashout row has refType "payout" and a refId matching exactly one payout whose ledgerEntryId is that row's id and whose credits equal the negated amount
  - each payout has exactly one such row, and its amountUsdCents equals credits × CASHOUT_USD_CENTS_PER_CREDIT
- `export function reconcileDemoState(s: DemoState): ReconcileReport` returns `reconcileLedger({ ledger: allLedger(s), payouts: allPayouts(s) })`.
