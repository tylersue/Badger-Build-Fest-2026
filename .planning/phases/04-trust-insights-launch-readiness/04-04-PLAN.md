Create features/benchmark/score.ts (pure; the formula is Claude's discretion under D-10):
- `export const BENCHMARK_DIMENSIONS` as a readonly array of `{ id: keyof BenchmarkMetrics; label; unit; direction: "lower" | "higher"; weight; best; worst }`:
  - costCreditsPerTask "Cost per task", credits, lower, weight 0.20, best 0, worst 60
  - tokensPerTask "Tokens per task", tokens, lower, 0.10, 0, 60000
  - secondsToAnswer "Time to answer", s, lower, 0.15, 0, 45
  - buildMinutes "Build time", min, lower, 0.10, 0, 480
  - taskSuccessPct "Task success", %, higher, 0.30, 100, 0
  - toolCallAccuracyPct "Tool-call accuracy", %, higher, 0.15, 100, 0
- `export function dimensionScore(dim, value): number` is a linear 0 to 100 score between worst and best, clamped.
- `export function overallScore(m: BenchmarkMetrics): number` is Math.round of the weighted sum of dimension scores.
- `export type BenchmarkRow = { id: string; name: string; kind: "expert" | "general"; category: Category | "all"; metrics: BenchmarkMetrics; score: number }`.
- `export function agentBenchmarkRow(agent: Agent): BenchmarkRow | null` returns null without data.
- `export function competitorRow(id: CompetitorId, category: Category | "all"): BenchmarkRow`. For "all", each metric is the mean across the three categories.
- `export function agentComparison(agent: Agent): BenchmarkRow[]` returns the agent's row followed by Muse, Grok and Hermes for the agent's category, or [] without data.
- `export function leaderboard(agents: Agent[], category: Category | "all"): BenchmarkRow[]` includes agents whose status is "published", that have data, and whose category matches (or all), plus the three competitor rows for that category. It sorts by score desc, then name.
